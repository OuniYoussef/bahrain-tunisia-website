# Brand assets (IEEE)

These files are required by the IEEE Global Page Elements and Branding Requirements.
They are trademarks and must come from IEEE, never be redrawn.

| File to add | Where to get it | Used in |
|---|---|---|
| `ieee-master-brand-white.svg` | IEEE Master Brand and Logos: https://brand-experience.ieee.org/guidelines/master-brand-and-logos/ | Header (dark bars), footer |
| `ieee-master-brand-black.svg` | same page | Header on light backgrounds |
| `favicon/` (ico + iOS/Android touch icons) | IEEE favicon file set: https://brand-experience.ieee.org/download/ieee-favicon-2/?wpdmdl=8949 | `index.html` |
| Site identifier wordmark (optional, approved) | Request from the IEEE Experience Design team: exd-team@ieee.org | Header, upper left |
| Organising IEEE units' logos (student branches) | Your branch / section volunteer leaders | Footer "Organised by" strip |

Until the official files are added, the app falls back to the `*.PLACEHOLDER.svg` files so layout can be built.
Rules (summary): Master Brand in black or white only (blue is reserved for IEEE.org), minimum 100 x 33 px,
upper-right of the header, clear space = half the height of the I-E-E-E letters, alt text "IEEE",
links to https://www.ieee.org in the same window. No shadows, never as a background or watermark.
